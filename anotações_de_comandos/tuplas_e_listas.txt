variaveis compostas são variaveis que podem armazenar mais de um valor, como por exemplo listas e tuplas.
tuplas são um conjunto de informaçoes armazenadas da seguinte forma:

comidas = ("hamburguer", "pizza", "limonada", "frango")

desse jeito os dados ficam armazenados da seguinte forma:

comidas(0) = "hamburguer"
comidas(1) = "pizza"
comidas(2) = "limonada"
comidas(3) = "frango"

as tuplas são imutaveis, ou seja, não podem ser alteradas depois de criadas.
Já as listas são mutáveis, podendo ter seus valores alterados, adicionados ou removidos.

listas utilizam []

lanche = ["hamburguer", "pizza", "limonada", "frango"]

comidas[0] = "hamburguer"
comidas[1] = "pizza"
comidas[2] = "limonada"
comidas[3] = "frango"

no caso de querer alterar, é possivel, por exemplo:

lanche = ["hamburguer", "pizza", "limonada", "frango"]
lanche[3] = "banana"

com isso o 4° item que era frango vira banana
alem disso, é possivel adicionar itens as listas com o .append, como no exemplo:

lanche = ["hamburguer", "pizza", "limonada", "frango"]

lanche.append("feijão")    #adiciona feijão no final da lista

lanche[0] = "hamburguer"
lanche[1] = "pizza"
lanche[2] = "limonada"
lanche[3] = "frango"
lanche[4] = "feijão"

comandos com listas:

soma = sum(lista) #soma todos os números na lista

quantidade de valores = len(lista) #o len(lista) diz quantos numeros tem a lista, ex:

lista = [8.0, 7.5, 6.7, 0,5]

nesse caso o sum() daria 22.7 e o len() daria 4

slicing (delimita qual área da lista será exibida) porém o primeiro número não aparece caso seja digitado, o que é resolvido usando um numero menor, ex:

lista = [1, 2, 3, 4, 5]
cópia = lista [0:5]            # [1, 2, 3, 4, 5]
lista [:5]                     # [1, 2, 3, 4, 5]
lista [1:3]                    # [2, 3]
lista [1:4]                    # [2, 3, 4]
bolsonaro = lista [3:]         # [4, 5]
lista [:3]                     # [1, 2, 3]
print(bolsonaro)
print(cópia)
print(lista)

sinal de negativo serve para desconsiderar o número de casas no final, ex:

lista = [1, 2, 3, 4, 5]
cópia = lista[:-1]
print(cópia)
